# Добрый Шкаф

Запустите backend из папки `DobryShkaf` по его инструкции. Для запуска интерфейса из папки `frontend`:

```sh
npm ci
npm run dev
```

Сайт открывается на http://localhost:3000. Запросы к API идут на http://localhost:8080. Для другого адреса задайте `BACKEND_URL` до запуска или сборки. Для просмотра профиля нужен подтвержденный аккаунт на сервере.
