# Добрый шкаф

Запустите backend из папки `DobryShkaf` по его инструкции. Для локального запуска интерфейса из папки `frontend`:

```sh
npm ci
npm run dev
```

Сайт открывается на http://localhost:3000. Запросы к `/api` идут на http://localhost:8080. Для другого адреса задайте `BACKEND_URL` до запуска или сборки. Письма подтверждения доступны в Mailpit на http://localhost:8025.

Для диалогов, передач и восстановления пароля нужен сервер из актуальной ветки `backend`. Перед запуском сервера задайте `APP_PASSWORD_RESET_URL=http://localhost:3000/reset-password`, чтобы ссылка из письма открывала форму фронтенда.

Если Mailpit на Windows не отвечает по SMTP, добавьте переменную `MP_SMTP_DISABLE_RDNS: "true"` в `environment` сервиса `mailpit` в локальном переопределении Compose и перезапустите сервис.

Тестовые пункты можно загрузить по инструкции backend. Карта и список используют одну выдачу и общие фильтры. Выбор района доступен без геолокации.

Для Яндекс Карт задайте `NEXT_PUBLIC_YANDEX_MAPS_API_KEY` в `.env.local` и перезапустите фронтенд. Добавьте `localhost` и домен сайта в ограничение HTTP Referer ключа. JavaScript API загружается при открытии экрана с картой. Геопозицию предоставляет браузер.

```sh
npm run typecheck
npm run build
```
